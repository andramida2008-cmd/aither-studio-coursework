# Aither Studio — курсовая работа

Адаптивный сайт студии визуального производства с управлением новостями и медиа.

Рабочий сайт: https://aitherstudio.ru/ru/

## Возможности

- RU / US / UK версии, страницы услуг, проектов и контактов.
- Новости с текстовыми блоками, фото и видео, выбранной обложкой, сеткой миниатюр и lightbox.
- Промо-плеер и переключение роликов в одном окне.
- Админка: создание, редактирование, поиск, черновики, публикация по времени, скрытие, корзина и восстановление.
- Выбор обложки, сортировка медиа и загрузка частями до 2 GiB на файл.
- Серверная авторизация, CSRF, проверка форматов файлов и SQLite.

## Скачать весь проект

Полный исходный код и публичные медиа находятся в архиве **aither-studio-coursework.zip** в разделе **Releases → Coursework v1.0** этого репозитория. Архив содержит обычную структуру проекта, а не только готовые HTML-страницы. После скачивания распакуйте его и перейдите в папку `aither-coursework-2026-10-02`.

Пароли production, действующая база с заявками, ключи, серверные резервные копии и история приватного Git не включены. Вместо базы используется безопасная конфигурация публичного контента; локальная база создаётся при первом запуске.

## Локальный запуск (macOS / Windows / Linux)

Нужен Node.js 22.13 или новее и доступ к интернету при установке зависимостей. Отдельная установка PHP не требуется: для учебного просмотра используется PHP 8.3 WebAssembly.

```sh
npm install
node coursework.mjs setup
node coursework.mjs build
node coursework.mjs start
```

Открыть http://localhost:8788/ru/ . Другие версии: `/us/`, `/uk/`.

Админка новостей: http://localhost:8788/admin/news/ . Случайный локальный пароль создаётся автоматически и находится в `work/local-selfhost/private/login.txt`. Он относится только к вашему компьютеру. Изменения локальной админки не меняют рабочий сайт. Для остановки нажмите Ctrl+C.

## Структура и технологии

| Папка | Назначение |
|---|---|
| `app/` | React 19, TypeScript, Next.js 16: страницы и компоненты |
| `public/` | Публичные изображения, видео, legacy-сайт и общий media viewer |
| `selfhost/php/` | PHP backend, SQLite-схема, API и редактор новостей |
| `selfhost/prepare.mjs` | Подготовка frontend к статической сборке |
| `selfhost/preview.mjs` | Локальная связь frontend с PHP/API |
| `coursework.mjs` | Учебный запуск и сборка |
| `lib/`, `worker/`, `build/` | Исходный Cloudflare/Vite контур проекта |
| `migration-backup/2026-09-02/` | Только безопасная публичная конфигурация и медиа для учебного запуска |

Production использует статическую frontend-сборку и PHP/SQLite на REG.RU. Локальный просмотр повторяет эту связку с PHP WebAssembly. Исходный Cloudflare-контур также сохранён для изучения архитектуры.

## Проверка

```sh
node selfhost/test-php.mjs
```

Набор из 72 серверных проверок охватывает авторизацию, публикацию, черновики, расписание, корзину, медиа и загрузку частями. Сборка `node coursework.mjs build` также проверяет TypeScript.

Для защиты курсовой можно показать: сайт → админка → создание черновика → загрузка нескольких медиа → выбор обложки → предпросмотр → публикация → проверка в ленте → скрытие и восстановление.

Внешние видео YouTube/Rutube требуют интернета. Медиа, добавленные на рабочий сайт после этой учебной копии, не синхронизируются автоматически. Репозиторий не подключён к автоматическому production-деплою.
